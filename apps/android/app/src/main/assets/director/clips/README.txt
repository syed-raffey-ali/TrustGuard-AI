Director clip files
===================

This folder holds the pre-recorded scam-call audio clips used by the Director
Panel demo.

Naming convention:
    line_01.wav, line_02.wav, ... one file per scripted line index of the
    active scenario (see ../scripts/*.json).

How they are produced:
    Each clip is recorded ONCE by the team (a human voice actor reading the
    corresponding scripted line) and dropped into this folder as a plain
    PCM/16-bit .wav file. They are NOT generated by TTS at runtime.

How they are used:
    During a live demo, Phone B (the "scammer" phone running the Director
    Panel) plays these clips into the call so the victim phone's TrustGuard AI
    pipeline analyses real speech over the call WebSocket. This is a manual,
    pre-recorded playback flow — not a TTS loopback (Project Bible, Section 5).

Playback behaviour in the app:
    If a clip file listed on the Director Panel exists here, tapping Play
    plays it via MediaPlayer; if it has not been recorded yet, the app shows a
    "clip not recorded yet" toast.
